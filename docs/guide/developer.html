DEVELOPER GUIDE

Use Aegis to govern your project, or change Aegis itself.

Sections 1 to 4 are for teams putting Aegis in front of an engine. Sections 5 to 9 are for people who extend it. The fastest hands-on start is a project tutorial: each one comes from a kept real run through both front doors.

1. BUILD AND RUN

One Maven build, one runnable jar.

JDK 17 or newer and Maven 3.9 or newer. The default build reaches no external network. Besides embedded Apache Derby and Apache ZooKeeper, it starts one engine process: a Kafka 3.9.1 broker on loopback for the Kafka Admin test.

mvn -B clean install                         # all modules, tests, license headers, coverage gates
mvn -B -Preal-engines clean install          # adds the real-engine validation modules
java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --config my-aegis.yaml
java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --config my-aegis.yaml --stdio
java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --verify-audit audit/aegis.jsonl
java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --verify-audit audit/aegis.jsonl --checkpoints anchor/heads.jsonl
echo -n "$TOKEN" | java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --hash-token
java -jar aegis-gateway/target/aegis-gateway-2.0.0-SNAPSHOT-all.jar --openapi-draft openapi.yaml draft.yaml --source-id orders --base-url https://orders.internal.example
docker build -t aegis-gateway:2.0.0-SNAPSHOT .            # non-root image; plugins go in /opt/aegis/plugins
helm install aegis charts/aegis -f my-values.yaml          # StatefulSet, one audit journal volume per replica

For a Spark Connect source use examples/aegis-gateway-spark/target/aegis-gateway-spark-2.0.0-SNAPSHOT-all.jar, and for the Kafka Admin source examples/aegis-gateway-kafka/target/; the commands are the same. Exit codes of the command-line modes: 0 success, 1 broken audit chain or manifest, 2 usage error. A configuration error stops start-up with a message that names the key.

2. WRITE A CONFIGURATION

Start from the closest profile; unknown keys stop start-up.

Shared profiles live in adopters/configurations/<name>/<name>.yaml (Spark, Spark Connect, Flink, Iceberg, Kafka, an A2A agent, an existing MCP server, and the teaching template template/TEMPLATE.yaml), and 25 adapter profiles in adopters/configurations/adapters/. The minimum file has sources, policy, audit.file and a host section. Every key is in the configuration reference.

StepWhy
Classify every tool with classAn unclassified tool is DESTRUCTIVE; MUTATE and DESTRUCTIVE need an independent per-call approval, and DESTRUCTIVE also a fresh dry-run receipt.
Name the resources each tool touches (resources: [{type, pointer}])Policy rules and scopes match typed resources, not raw arguments.
Give destructive tools a real preview (dryRun)The backend's validate-only flag (ARGUMENT) or a read tool (TOOL) shows the approver the actual target.
List every backend host in egressEvery HTTP destination, including URLs inside arguments, is checked; everything else is denied.
Start a REST API from its OpenAPI document--openapi-draft writes every operation as a DESTRUCTIVE tool with a deny-all policy and lists what it could not express; classify, trim and write policy before use.
Give the backend each user, not one accountcredentials: {type: token-exchange, tokenEndpoint, clientIdEnv, clientSecretEnv, audience} exchanges the caller's verified JWT per call (RFC 8693). Own host with JWT identity only; no fallback.
Pick a secrets.sourceenv (default), file (a mounted directory) or vault (one KV v2 secret). The names in the file stay the same.
Use catalog.mode: REQUIRE_PINS with signed pinsA catalog.manifest signed off the gateway host decides which tool definitions may run.
Add audit.checkpointExports the journal head to storage the journal writer cannot rewrite, so truncation and regeneration are detected.

3. CONNECT A CLIENT OR IDE

Streamable HTTP, stdio, or through Knox.

  • Own host, HTTP. POST http://host:8080/mcp with Authorization: Bearer <token>. 2026-07-28 clients send MCP-Protocol-Version, Mcp-Method and Mcp-Name headers that must match the body; 2025 clients call initialize and use the Mcp-Session-Id they receive.
  • Own host, mutual TLS. With host.tls.clientAuth: require the client presents a certificate from the clientCaFile bundle; with identity.type: spiffe that certificate is an X.509-SVID mapped to a caller.
  • stdio. Run the jar with --stdio; the caller is host.stdio.
  • Knox. https://<knox>/gateway/<topology>/aegis-mcp/v1/mcp; Knox authenticates and checks the route ACL, Aegis governs the call.
  • Controls go in params._meta: io.github.vaquarkhan.aegis/dryRun, .../approvalToken, .../dryRunReceipt, and optionally a W3C traceparent.
  • Decisions come back in result._meta["io.github.vaquarkhan.aegis/decision"] for tools, and as JSON-RPC error -32010 with the deny code for resources, prompts and completion.

Each project tutorial ships VS Code, Kiro and Cursor files for both doors in adopters/tutorials/<project>/ide/. The token you give the IDE decides who the assistant is to Aegis.

4. OPERATE

Approvals, definitions, audit and health.

Decide an approvalGET /aegis/v1/approvals, then POST /aegis/v1/approvals/{id}/approve or /deny as an approver; the requester collects the single-use token with GET /aegis/v1/approvals/{id}. A requester cannot approve their own request.

Probe and measure/healthz; /readyz answers 503 until at least one tool is active; /metrics in Prometheus text, authenticated like /mcp.

6. EXTENSION POINTS

ServiceLoader interfaces and in-process seams.

InterfaceSelected byContract

config.spi.GovernanceHookFactoryhooks[].typeBuilds a GovernanceHook: deny before a call, rewrite or withhold after it.

engine.spi.DecisionListenerembedding hostObserves decisions (metrics, tracing); cannot change them.

Register a factory in META-INF/services/io.github.vaquarkhan.aegis.config.spi.<Interface>. Built-in names (mcp, http, memory, env, file, vault) always select the built-in implementation, and a hook factory that claims a built-in hook name stops start-up.

7. WRITE A SOURCE PLUGIN

Capability only: descriptors and executors.

public final class MyEngineToolSourceFactory implements ToolSourceFactory {
    @Override public String type() { return "my-engine"; }

    @Override public ToolSource create(String id, ConfigNode s) {
        String host = s.requiredString("host");          // read every key you support;
        int port = (int) s.integer("port", 9000);        // unknown keys fail start-up
        return new MyEngineToolSource(id, host, port);   // discover() returns descriptors and executors
    }
}
  • Classification, resources, groups and previews come from the operator's tools: section, never from the source.
  • ToolExecutor.egressTargets returns the backend endpoint (as http(s)://host:port for non-HTTP protocols) so the egress guard sees it.
  • Use ExecutionContext.credentials() and forward ExecutionContext.traceparent() when the protocol carries metadata; honour timeoutMillis().
  • Caller mistakes are a ToolResult with isError: true; outages are an ExecutionException and count towards the circuit breaker.
  • Never build a query by concatenating an argument; validate identifiers and quote them.
  • aegis-source-a2a is a small worked example with no dependencies beyond the Aegis modules: card discovery, an origin rule for the endpoint, bounded HTTP and reply mapping.
  • Return true from dispatchesByUpstreamName() only if one executor serves several tools by upstreamToolName(); that enables dry-run mode TOOL.

8. WRITE A GOVERNANCE HOOK

In another process, or in-process.

Without Java: configure hooks: [{type: remote, settings: {url: ...}}] and answer {"allow": true|false} over HTTP; the URL passes the egress check at start-up. In-process: implement GovernanceHook and ship a GovernanceHookFactory (aegis-mcp-guardrails is a worked example). For the remote path, adopters/hooks has three reference services in Python's standard library (PII guard, secrets guard, change window) with unit tests and a live run against the gateway jar.

  • before(Context) may deny with POLICY_DENIED, INVALID_INPUT or PROMPT_INJECTION.
  • afterTool(Context, ToolResult) and afterContent(Context, Map) may rewrite or withhold a result; throw HookDenied(code, reason) to withhold with a reason that reaches the audit record.
  • Operators narrow a hook with operations, methods, groups and sources, and choose ENFORCE or AUDIT. In ENFORCE a hook that throws denies.

Rule. A test whose real target is not configured reports skipped, never passed. Protocol fixtures (TestMcpServer) and the adapter contract harness prove protocol and route behavior, not compatibility with a named product. What each run established is in VALIDATION and the claims matrix.

10. TUTORIALS

One per project with a kept real run.

The tutorial index lists the deep-dive tutorials (Spark and Iceberg, Spark and Spark Connect, Iceberg, Kafka, Flink) and one IDE-ready tutorial per verified project, built by tools/build-project-tutorials.py from that project's kept two-door run. Twenty-five generated tutorials cover the Keep-verified engines, including Airflow, CouchDB, Doris, Druid, Hadoop, HBase, NiFi, Pinot, Storm, and Superset. Projects with a configuration but no real run (Atlas, Cassandra, Hive, Impala, Paimon, Ranger) have no tutorial.

Security reviewers should start with the HTML security guide (threat zones, TM01 to TM10, OWASP MCP handling, S1 to S31, and the latest control-suite evidence) before reading THREAT-MODEL and SECURITY.

11. CONVENTIONS

From AGENTS.md.

  • Fail closed: if a control cannot decide, deny.
  • Reuse the stable deny codes in DENY-CODES.md; new ones need review.
  • Apache License 2.0 header on every file that can carry one (RAT runs in the build).
  • Keep the engine, mcp and config modules free of third-party runtime dependencies.
  • Humans commit; agents propose. Disclose AI assistance in the pull request.
